# ReverseContact agent skills

Agent skills for [ReverseContact](https://reversecontact.com), a B2B data enrichment API.

## Install

```bash
npx skills add visum-run/skills
```

## Available skills

| Skill | Description |
| --- | --- |
| `reversecontact-cli` | Drive the `rc` CLI: enrich people and companies, fetch by LinkedIn URL or id, search, check freshness for free, resolve contact emails, poll async live jobs, and inspect credits. |

The `reversecontact-cli` skill is generated from `apps/cli/skill/` in the ReverseContact monorepo and published here by the CLI release workflow. Open issues against the CLI itself rather than editing this mirror.
